A deep-learning framework written from scratch

Autograd, layers, optimizers and a GPT, in pure NumPy.

Sutra is a PyTorch-style framework built without PyTorch. Every backward pass is derived by hand and checked against PyTorch. It trained the two models on this page, which now run in your browser on a 250-line JavaScript engine.

How the engine works

        
Each operation records its inputs and a closure that maps the output gradient to input gradients. backward() sorts the graph topologically without recursion and runs those closures in reverse. Hot paths such as convolution, attention, the norms and cross-entropy have fused, hand-derived backward passes.

      

      


import sutra as st
from sutra import nn, optim, F

model = nn.Sequential(
    nn.Conv2d(1, 16, 3, padding=1),
    nn.BatchNorm2d(16), nn.ReLU(),
    nn.MaxPool2d(2), nn.Flatten(),
    nn.Linear(16 * 14 * 14, 10))
opt = optim.AdamW(model.parameters(), 3e-3)

for x, y in loader:
    loss = F.cross_entropy(model(x), y)
    opt.zero_grad()
    loss.backward()        # reverse-mode autodiff
    opt.step()

# fused attention backward, derived by hand:
# dV = Pᵀ·dO     dP = dO·Vᵀ
# dS = P ⊙ (dP − rowsum(dP ⊙ P))
# dQ = dS·K/√d   dK = dSᵀ·Q/√d

        

          
tensor.py
Tensor, broadcasting-aware autograd engine, 40+ differentiable ops, no_grad, retain_grad

          
functional.py
conv2d via im2col, pooling, fused attention, LayerNorm, BatchNorm, softmax, cross-entropy with label smoothing

          
nn.py
Module system with parameter registration, buffers, state dicts, train/eval, and the standard layers

          
optim.py
SGD with Nesterov, Adam, AdamW, RMSprop, param groups, gradient clipping, cosine warmup

          
tokenizer.py
Byte-level BPE with incremental pair counts, trained in 0.4 s on 1 MB

          
models/gpt.py
GPT-2-style decoder with weight tying, KV-cache sampling, top-k and nucleus sampling

          
quantize.py
Per-row symmetric int8 post-training quantisation

          
web/sutra.js
The browser inference engine used by the demos on this page
